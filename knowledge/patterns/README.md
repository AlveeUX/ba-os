# Patterns

Reusable checklists that `/ba-start` adds to a project's profile and `/ba-check` uses to find gaps.

- `common-gaps.md` — used on every project.
- `hospitality.md` — hotels, resorts and serviced apartments.
- Add a domain file (for example `ecommerce.md`, `clinic.md`) after a project in that domain teaches you something. `/ba-learn` proposes these. Keep each file a short list of questions, not a document.

Never copy client names, prices or personal data into this folder.
