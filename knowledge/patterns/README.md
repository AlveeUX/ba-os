# Patterns

Reusable checklists that `/ba-start` adds to a project's profile and `/ba-check` uses to find gaps.

- `common-gaps.md` — used on every project.
- Add a domain file (for example `hotel-booking.md`, `ecommerce.md`) after a project in that domain teaches you something. Keep each file a short list of questions, not a document.

Never copy client names, prices or personal data into this folder.
