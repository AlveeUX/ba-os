# Projects

One folder per project, named `P-<year>-<number>-<short-name>`, for example `P-2026-001-hotel-booking`.

- Start a project with `/ba-start <short-name>` inside Claude Code.
- Confidential projects go in `_confidential/`.
- `active.md` (created by `/ba-start`) names the project every `/ba-` command works on. To switch, run `/ba-status <project-id>`.
